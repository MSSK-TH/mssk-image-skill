v1.5.1 实测校准与诊断加固（2026-11-23）
------------------------------
  · 修复 chat 模式 GPT-5.6 Sol 的真实 slug：由错误的 `gpt-5.6-sol-thinking` 改为实测真值 `gpt-5-6-thinking`（即时档 `gpt-5-6-instant`，GPT-6 即时档 `gpt-6-instant`），消除 prepare 阶段 `conduit_token` 失败降级。
  · 修复 work 模式档位全面错位与 422 报错：
      - `EFFORT_ORDER` 补入上游真实轻度值 `"min"`；
      - `WEB_WORK_TIERS` 对齐上游真实 5 档：`轻度(min) / 中(standard) / 高(extended) / 极高(xhigh) / 最高(max)`；
      - `work` 模式下历史写法 `--effort minimal` 自动映射为 `min` 并给明确告警，消除 `422 Invalid conversation body`；
      - 传旧错误 slug（`gpt-5.6-sol-thinking`）、`-instant` 搭思考档或跨模式混用 `-wm` 时提前给出告警。
  · 细化网页管线降级/失败诊断：
      - `relay_errors.py` 新增 `webpipe_invalid_request`（`conduit_token` / `422 Invalid conversation body`，不重试）与 `webpipe_blocked`（`webpipe 403` / Cloudflare / Sentinel，不重试）；
      - `_report_pipeline` 降级警告附带诊断建议，`_report_record` 补齐独立 `"degraded_reason"` 字段；
      - `_resolve_timeouts` 按显式 `--timeout` 缩放 `slow_after`（`min(base_slow, max(20, timeout*0.6))`），避免重任务短超时下 `[slow]` 永不触发。
  · `WEB_WORK_MODELS` 按上游版本选择器新到旧排序（6.2 Astra → 5.6 Luna，共 10 个已核验 `-wm` 模型），同步更新 SKILL.md / cli.md / relay-api.md / selfcheck.py。

v1.5.0 新增与修复（2026-11-23）
------------------------------
  · 修复 11 个 @4k 预设全挂：_apply_preset 上限对齐 GPT_IMAGE_2_MAX_PIXELS（8,294,400）。
  · 修复 generate-batch 读 JSONL 未去 BOM（改用 utf-8-sig），解决 PowerShell 首行 JSON 变纯文本。
  · 错误分类单一真相源（relay_errors.py）：
      - 删去 image_gen.py 重复人话化代码（同时修掉 sexual/minors 被 `/` 误切 bug）
      - 修复 503 system cpu overloaded 被当可重试猛撞 3 次且错打 RETRYABLE=yes
      - 修复 no_image_data 匹配不到 "returned no images" 导致配错通用 HINT
      - 修复 _is_refusal_error 扫不到人话化拒绝导致 --retry-refusal 失效（并跳过确定性 stage=input）
      - 补全 timeout / deadline_exceeded / network_error / rate_limited / no_channel 及 HTTP 401/408/429 兜底
      - stderr RAW= 与 --report-json 强制脱敏 sk-* / Bearer / api_key
  · 消除结构性重复与全局可变态：
      - 删去重复定义的 _cmd_setup
      - 统一 _prepare_prompt / WireStyle（style.mssk_* ↔ multipart web_* 单一映射表） / _run_with_refusal_retry
      - 去掉 _LAST_PIPELINE / _EXACT_SIZE_REQUEST 全局态（消除 batch 并发竞态与进程内残留）
      - --dry-run 严格零磁盘副作用（不写 .imagegen/conv-*），edit/batch 预览如实包含 style，reference 预览脱敏 base64
      - config.json 默认值仅注入网页管线命令，消除 setup 后 reference 必刷的误报 Warning
  · 新增可用性与幂等能力：
      - setup --show [--json]（安全只读查看配置状态，绝不暴露 api_key）；拦截 work + --effort none
      - --agent-model auto 可单次覆盖 config.json 回到 auto
      - 付费调用前 Fail-Fast 预检目标路径与目录可写性 + 原子写盘（tempfile + os.replace）
      - 修复 n>1 多余产物命名 bug（foo-1..foo-4 而非 foo-1-1）+ --report-json 记录真实落盘路径与 PNG/GIF/JPEG/WebP 像素
      - 新增 generate --strict-n（拆 N 次 n=1 严格出图）与 generate-batch --skip-existing
      - 支持 config.json 可选 "edit_contract": "openai-multipart" 固定契约（不写额外隐藏缓存文件）
  · 分层超时与 deadline 穿透修复：
      - 修复 refusal 重试循环内重置 deadline、reference SSE keepalive 永不超时、URL 下载无视 deadline 三处 bug
      - 默认超时分层：常规单图 150s/240s，重任务（n>1 / work / extended+ / reference）300s/480s；>=60s 超时最多自动重试 1 次；读取 HTTP Retry-After 响应头；心跳超阈值升级 [slow]
  · 文档对齐官方 imagegen（.system/imagegen）：
      - SKILL.md 保留官方完整骨架与提示词段（When to use/not to use、Decision tree、Workflow、Specificity policy、19 个 Use-case 定义、Shared prompt schema、Examples、Prompting best practices、非覆盖保存规范），消除 7 处矛盾并从 877 行（49 KB）精简至 ~270 行（~19 KB，与官方 315 行 / 19.5 KB 基本等长）
      - 消融实验数据与浏览器对比排障下沉至 references/safety-refusals.md
      - references/cli.md 对齐官方章节结构（补回 Guardrails / Mask notes / Recipes），references/relay-api.md 同步更新
  · 自检升级：selfcheck.py 修复 edit 并集盲区，覆盖上述全部回归项（58 项零成本自检）。
