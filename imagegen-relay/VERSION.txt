v1.4.0 新增（2026-11-19）
------------------------------
  · 网页管线三件套：--web-mode chat|work、--effort（推理档）、--agent-model（上游 slug），
    全部走 style.mssk_mode / mssk_effort / mssk_model（顶层字段会被 new-api 丢掉）。
  · tiers 子命令：打印推理档（与 web 前端同一套中文标签；work 模式只有 5 档滑杆）。
    注意两套值并存：work = minimal/low/standard/extended/max，
    chat = 账号 presets 声明的值（实测见过 medium/high/xhigh/ultra）。
  · 失败可编程：新增 scripts/relay_errors.py（镜像 image-web/lib/errors.mjs），
    失败时 stderr 打印 CODE= / RETRYABLE= / HINT= / RAW=，
    --report-json 同时落一份 {ok:false,error:{code,hint,retryable,http_status,raw}}。
  · 会话钥匙改为按项目隔离：<cwd>/.imagegen/conv-<hash(user+cwd)>（原来是一个全局
    .conv-key，同机两人或两个项目会互相覆盖）；--conv-key 仍可显式指定。
  · SKILL.md 新增：参数推断表（从用户话里取，不问）、只在三种情况下才问用户、
    错误码→行动对照表；references/cli.md 与 relay-api.md 补对应说明。
  · 未改动：6 个与官方 imagegen 逐字节一致的文件、config.json、bin/、会话续接与 GIF 逻辑。

  共用代码提醒（改这三处会同时影响两条管线）：foldParams / passthrough / relay_errors。

v1.3.0 新增（2026-11-06 实测）
------------------------------
  · 动图 GIF：data[i].mime_type=image/gif 时按原字节保存（不重编码、不丢帧），
    自动改扩展名 .gif，跳过 --exact-size / --downscale，并写出 <name>-sprite.png
    + 打印 animation（rows/columns/frame_count/frame_duration_ms）
  · --gif-speed {0.25..2}：8 档，走 style.mssk_gif_speed（顶层字段会被 new-api 丢掉），
    只缩放 animation.frame_duration_ms，GIF 文件本身仍是 1x
  · 多图：上游一次可能回多张（实测 4~5 张），data[] 每项写一个文件
    （base.png → base.png / base-1.png / …），不再只有第一张

默认值（出厂状态）
------------------
  图像模型            gpt-image-2（本中转站唯一）
  reference 路线模型  gpt-6-astra
  --preflight         off      ← 不自动改你的提示词
  --retry-refusal     0        ← 被拒不自动重发（一次算一次）
  --deadline          600 秒   ← 单任务硬上限，杜绝"跑 20 分钟才失败"

已固化的能力
------------
  · 两条路线：reference（/v1/responses + 图像工具，模型自己融合参考图）
              generate / edit / generate-batch（/v1/images/*，官方 fallback 同构）
  · Codex JSON 契约与 OpenAI multipart 契约自动探测（edit）
  · 输出层安审判别：按延迟区分"提示词层 / 输出图层"，附消融实测数据
  · 内容安全拒绝处理流程（Relay fact 7）+ 紧凑中性简报模板
  · 人物简报规则：必须写明服装，但写成"一句覆盖/一致性约束"，不逐件列举
  · 心跳日志 + 干净报错（不再吐 traceback）
  · 动图 GIF + sprite sheet + 8 档速度（v1.3.0）
  · 一次多图全部落地（v1.3.0）

实测基线（同一渠道、同一参考图）
--------------------------------
  逐件列举服装的长简报                    0 / 5   全拒
  一句话覆盖约束的紧凑简报                2 / 2   通过（且保留原服装）
  跨 4 张参考图 8 次单跑                  3 / 8   ≈ 37%（输出层判定随机）

可选择的开关（默认都关着）
--------------------------
  --preflight auto|always   自动中和风险词 + 追加覆盖约束（每条改动都会打印）
  --retry-refusal N         被拒后换中性措辞重发 N 次
  --reasoning-effort high   reference 路线给改写模型开高（不要用 -high 模型 ID，会 500）
  --report-json PATH        落一份 JSON 报告（含最终提示词、actual_size、耗时）
